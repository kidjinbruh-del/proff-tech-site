# PROFF.tech — частный макет для просмотра с телефона

**Live-превью (доступ только владельцу):** https://profftech-fiz-review-20261118.proff-tech-2693.chatgpt.site

Репозиторий приватный; GitHub Pages не включён. Для автономного просмотра:

1. Войдите в GitHub под аккаунтом с доступом к репозиторию.
2. Скачайте ZIP этой ветки: [review/physical-mobile-nov18](https://github.com/kidjinbruh-del/proff-tech-site/archive/refs/heads/review/physical-mobile-nov18.zip).
3. Распакуйте архив на телефоне и откройте `mobile-physical-preview.html` (макет телефона 390 px) или `index.html` (ширина экрана телефона).

В автономной копии использованы относительные пути, поэтому изображения и шрифты загружаются из папки архива. Яндекс Метрика отключена, просмотры макета не попадут в рабочую статистику.
