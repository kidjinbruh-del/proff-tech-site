# PROFF.tech — лендинг ремонта бытовой техники

Одностраничный сайт компании «Профтех» (PROFF.tech) для трафика из Яндекс Директа: дизайн-концепция, живой прототип и CI.

**Сайт:** https://kidjinbruh-del.github.io/proff-tech-site/
**Дизайн-спецификация:** [docs/design-spec.md](docs/design-spec.md)

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | весь лендинг: разметка, стили, анимации, скрипты. Один файл, 45 КБ, без сборки и зависимостей |
| `docs/design-spec.md` | концепция: палитра, типографика, анимации по блокам, библиотеки, тексты, требования Директа и 152-ФЗ |
| `tools/check_site.py` | валидатор страницы (разметка, якоря, иконки, https, бюджет размера) |
| `tools/deploy_site.ps1` | публикация `index.html` на github.io вручную |
| `.github/workflows/ci.yml` | CI: валидация на каждый push/PR + артефакт для деплоя |
| `.github/workflows/deploy.yml` | публикация на github.io (нужен секрет `PAGES_DEPLOY_TOKEN`) |

## Стек

Статический HTML + CSS + ванильный JS. Внешние зависимости: шрифт Inter (Google Fonts) и одно фото-плейсхолдер (picsum.photos). Сборки нет: файл открывается напрямую.

Анимации: `IntersectionObserver` для появлений, CSS `animation-timeline: view()` для parallax и «прорисовки» таймлайна (с фолбэком), canvas-частицы в hero, всё под `prefers-reduced-motion`. Слушателей события `scroll` нет.

## Локальный просмотр

```powershell
Start-Process index.html
```

Для проверки перед коммитом:

```powershell
python tools/check_site.py index.html
```

## Деплой

Схема: исходники в приватном репозитории, раздача — из публичного `proff-tech-site` через GitHub Pages (бесплатный план не включает Pages для приватных репозиториев).

**Вручную с машины разработчика:**

```powershell
powershell -File tools/deploy_site.ps1
```

**Из CI:** добавить секрет репозитория `PAGES_DEPLOY_TOKEN` (fine-grained token с правом `contents: write` только на `proff-tech-site`). После этого `deploy.yml` публикует страницу на каждый push в `main`; без секрета job пропускает публикацию.

## Перед запуском рекламы заменить плейсхолдеры

В `index.html` они помечены комментариями `<!-- mock -->` / `<!-- TODO -->`:

- телефон, e-mail, часы работы, город и адрес;
- реквизиты: наименование, ИНН, ОГРН (обязательны для модерации Директа по тематике «ремонт техники»);
- цены «от» — по реальному прайсу; сроки гарантии; SLA обратного звонка;
- фото мастера/процесса вместо picsum, при наличии — 3D-иконки техники;
- страницы «Политика обработки персональных данных» и «Публичная оферта» (сейчас ссылки-заглушки `#privacy`, `#offer`);
- текст согласия — по шаблону из `docs/design-spec.md` §6.1 и `research/ru-compliance.md`.

## Соответствие требованиям

Ключевое из спецификации: нет автопопапов (модалка только по клику), блок реквизитов в футере, условия «0 ₽» стоят рядом с обещанием, нет превосходной степени, отдельный непредустановленный чекбокс согласия, политика — ссылкой у формы.
